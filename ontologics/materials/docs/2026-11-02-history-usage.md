# 가상 생산 이력 기반 공정 자재 추정

사용자가 가상 이력을 이용한 현실적인 추정을 요청했다. 기존 저장소에는 사용 이력이 없으며 RFQ 검토를 실사용으로 전환하지 않는다. materials 내부에 가상 출고/반납/준비 사용량을 별도 생성한다.

실제 치수: 기존 고정 커밋 PCB, 외곽면적, 두께, BAT1/C25/C27/LAN_CON1 드릴 치수. 제조사 값: 실납 외경/코어함량, SAC305 밀도. 가정: BAT1 두 접점은 수작업, C25/C27 네 접점과 LAN_CON1 전기핀 10개는 납조, 해당 범위는 상호 배타적. 전체 실제 제조 공정으로 주장하지 않는다. 세정은 액상 IPA로 양면 두 번 닦는 가정이며 실제 no-clean 보드에 세정이 필요하다고 주장하지 않는다.

6개 배치/구성 × 2구성 × 3자재의 가상 기록을 결정론적 물리모델로 생성. 주어진 공정 조건의 변화는 모두 파일에 기록하며 난수는 사용하지 않는다. 동일 제품·공정·자재·단위, 완료, 기준일 이전 이력만 조회. 최소3배치, 생산수량 가중 평균 = Σ(출고−반납−준비량)/Σ생산대수. 준비량은 별도 평균으로 한 작업에 한 번 반영. 초기 납조 충전은 제외, 기존 충전된 납조를 사용하는 가정. 여유율은 관측 손실과 별개로 추가 계획 버퍼임을 표시.

구현: 재현 스크립트/JSON → 근거 검증 후 런타임 보완 → 대당/준비량 계산·RFQ → UI에서 사용한 이력과 가정 확인. 실재고를 차감하지 않는다. 데이터 부족/다른 공정 이력은 미등록 상태를 유지한다. 가상 이력은 실제 관측 표본이 아니므로 정확도/국가인증을 주장하지 않는다.

## 생성 값과 출처 구분

- 실납: 제조사 외경0.8mm/코어2.2%, SAC305밀도7.37g/cm³는 기존 공개자료. 코어밀도1g/cm³, BAT1접점당2.8~3.2mm 투입, 투입손실5%는 가정. 준비0.5g은 인두팁 주석도금·시작 손실 가정(계산 밀도로 약150mm의 와이어). 제조사 사용량 권고 아님.
- 세정제: 실제 외곽22.28331621cm²를 양면2회 닦는 작업 가정. 등가 젖음두께0.1mm, 천 잔류·증발계수2.5~3.0은 가정. 준비10mL는 보드별 닦기와 별도인 도구/작업대 초기 세척 가정. no-clean 보드의 필수 세정 주장 아님.
- 솔더 바: C25/C27(4핀), LAN_CON1전기핀(10핀)의 실제 드릴/PCB두께를 사용. 핀직경0.6mm, 필렛체적배수1.3, 드로스10~15%는 가정. 준비2g은 시작 시 드로스 손실 가정이며 납조 충전량이 아니다.
- 6개 가상 배치(100/150/200/250/300/400대) 합계1,400대. L/L1은 해당 접점/치수가 같으므로 추정 기준도 같다. 이는 독립적인 실측 재현성 증명이 아니다.
- 결과: 실납0.020568g/대+준비0.5g, 세정제2.473449mL/대+준비10mL, 솔더바0.111385g/대+준비2g. 대당 가중평균은 출고−반납−준비 사용량으로 계산하고 여유율은 추가 계획 버퍼로 분리한다.
- 공식 규격/용도 확인: https://www.kester.com/products/product/275-flux-cored-wire 및 https://mgchemicals.com/downloads/tds/tds-824-l.pdf . 대당 수량은 이 문서가 보증하지 않는다. 기존 원문/해시/라이선스는 변경하지 않는다.
