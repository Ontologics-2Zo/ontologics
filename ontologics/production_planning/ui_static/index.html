04
검토 문서
생산 계획·대체 검토안·견적 및 납기 확인 요청을 검토하세요.
생산계획을 계산하면 문서가 생성됩니다.
문서는 검토용 초안입니다. 다운로드는 승인·발주·외부 송부가 아닙니다.


개발 테스트 설정
운영 기능이 아닌 시험 환경 설정입니다. 시나리오를 바꾸면 현재 접수 화면이 초기화됩니다.
Alice로 접수 → Bob으로 주문 수량 확인 → Alice로 계획 계산. 실제 로그인이나 그래프 등록 승인이 아닙니다.


개발용 데이터는 서버 종료 시 삭제됩니다. 다운로드한 문서는 별도로 남습니다.
