첫 번째는 README의 확장 결과 검증 규칙과 main에 이미 있는 공통 후처리를 재사용한다. 두 번째의 schema 보류 방식은 README에 명시된 구현이 아니라, 미승인 초안 보존 원칙과 사용자의 결과 보존 요구를 지키기 위한 B 실행기의 예외 처리다. 공통 도구·공개 envelope·신원·권한·도메인·비용 정책을 변경하지 않았다.
