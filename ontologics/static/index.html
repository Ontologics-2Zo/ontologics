S1 · 로트 장착 이력 조회

고장·불량 판정 기능 아님

1조사 조건 설정

명시적 시각·시간대

B는 장착 구간과 조사 기간이 겹치는 이력입니다. 시작 포함·끝 제외 [start,end)이며, 실제 가동 시간은 추론하지 않습니다.

A와 B는 동일 데이터 버전으로 조회합니다.

2장착 이력 조회 결과

장착 이력 확인요청한 시점 또는 기간 조건에 일치하는 장착 이력이 확인됨

조건상 제외충분한 이력 근거가 있으며 요청한 조건에는 해당하지 않음

추가 이력 확인 필요제거 시점이나 이력 확인 범위 등 판단에 필요한 근거가 부족함

장착 이력 확인은 결함·고장 확인이 아니며, 조건상 제외도 안전하다는 뜻이 아닙니다. 확인된 이력이 있어도 다른 미확인 구간은 남을 수 있습니다.

3누락·미확인 장착/제거 이력 보완

가상 운영 기록

첫 통합 사례는 보존된 U104 시연 보완 근거를 사용합니다. 시연값을 불러와도 초안 저장·승인·반영은 실행되지 않습니다.

다른 시연용 가상 보완 자료는 「개별 보드·부품 로트 이력」에서 JSON 파일로 접수할 수 있습니다. 이 U104 템플릿은 선택한 원본이 뒷받침하는 값만 제출합니다.

확정 데이터는 바뀌지 않습니다. 같은 작업 재시도는 저장 버튼을 다시 누르세요.

4이력 보완 전·후 조사 결과 비교

최초 조회에서 고정한 대상·로트·A/B 조건을 유지하고, 선택한 초안의 실제 반영 데이터 버전과 비교합니다.

먼저 장착 이력을 조회하고 보완 초안을 선택하세요.
